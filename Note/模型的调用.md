# 模型的调用

在LangChain中，提供了几种核心的调用方式，主要是`invoke()`、`stream()`、`batch()`方法，以及他们的异步版本`ainvoke()`、
`astream()`、`abatch()`，下面将系统的介绍这些方法。

- `invoke()`：阻塞式，一次性返回完整结果回答、批处理任务、无需实时反馈的场景。
- `ainvoke()`：非阻塞式，提高系统吞吐量高并发Web应用、IO密集型任务。
- `stream()`：流式输出，实时返回每个Token聊天机器人、长文本生成、需要提升用户体验的交互应用。
- `astream()`：非阻塞式，提高系统吞吐量高并发Web应用、IO密集型任务。
- `batch()`：批量处理多个输入高并发场景，需要同时处理大量请求。
- `abatch()`：非阻塞式，提高系统吞吐量高并发Web应用、IO密集型任务。

# invoke

## invoke的input

### 1. 字典列表

创建字典列表组成消息。一条消息，通常包含`role`、`content`等信息。

使用场景：可以设置系统提示词，表达多轮对话历史，JSON兼容，易于序列化和网络传输。

格式：

```python
message = [
    {"role": "system", "content": "系统提示词"},
    {"role": "user", "content": "用户消息"},
    {"role": "assistant", "content": "AI回复"},
    {"role": "user", "content": "继续提问"},
]

```

角色说明：

| 角色      | 作用                           | 示例                       |
|-----------|--------------------------------|----------------------------|
| system    | 设定AI的行为、角色、规则       | “你是一个专业的Python导师” |
| user      | 用户的输入/问题                | “什么是装饰器”             |
| assistant | AI的历史回复（用于对话上下文） | “装饰器是一种设计模式...”  |

### 2. 文本输入

直接输入文本`invoke("你是谁")`。

### 3. 消息对象列表

```python
from langchain.chat_models import init_chat_model
from langchain_core.messages import SystemMessage, HumanMessage, AIMessage

model = init_chat_model(
    model="openai:deepseek-flash"
)

messages = [
    SystemMessage(content="你是一个老外，能听懂中文，但是只会说英文"),
    HumanMessage(content="山外青山楼外楼，西湖歌舞几时休的英文是什么？")
]

response = model.invoke(messages)
```

常用的有以下几个：

| 消息类        | 对应字典格式              | 作用       |
|---------------|---------------------------|------------|
| SystemMessage | {"role":"system", ...}    | 系统提示词 |
| HumanMessage  | {"role":"user", ...}      | 用户输入   |
| AIMessage     | {"role":"assistant", ...} | AI回复     |

> PS：记忆传递使用response.append ()方法进行传递上下文，让模型有一定的记忆功能。

# stream

## stream 的 input

stream的输入内容可以与invoke一致

## stream 的 output

stream方法调用之后会实时的返回响应片段。会返回一个iterator (迭代器)，可以通过循环的方式处理每一个chunk内容块。

# batch

## batch 的 input

传入的是一个列表，里面是多次的提问内容，例如：

```python
messages = [
    "你是谁？",
    "1+1=?",
    "Deepseek是谁？",
    "Python是什么？"
]

```

## batch 的 output

返回的结果也是一个列表,返回的结果跟 invoke 格式一样，但是是好几个invoke的结果，可以理解为是运行了好几次invoke，然后把所有结果一起返回出来。
